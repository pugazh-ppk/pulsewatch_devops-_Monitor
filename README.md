# PulseWatch - DevOps Website Monitoring System

PulseWatch is a simple website monitoring application
designed to check website availability and monitor
HTTP status codes and response times.

## Features

- Website availability monitoring
- HTTP status code checking
- Response time measurement
- Monitoring history
- Simple dashboard

## Technologies Used

- Python
- Git
- GitHub
- GitHub Actions
- Docker

## Project Goals

- Learn Git version control
- Implement a CI pipeline
- Containerize the application using Docker
- Understand DevOps workflows
